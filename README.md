# TO-DO List Application

## Describtion

This program is a bash script to store tasks in a text file and allow the user to add, list, and delete tasks.

## Features

Tracking task lists
Listing tasks
deleting tasks
prompting color coded outputs

## installatiom

navigate to the folder: cd into todo.sh
run the script: ./todo.sh

## usage

Pulls data
